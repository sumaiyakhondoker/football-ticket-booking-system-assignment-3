# Football Ticket Booking System

This is a PostgreSQL database project for a Football Ticket Booking System.

## Tables

- Users
- Matches
- Bookings

## Relationships

- One User can have many Bookings.
- One Match can have many Bookings.
- Bookings connects Users and Matches.

## SQL Queries

The `query.sql` file contains the required SQL queries using:

- WHERE and ILIKE
- NULL and COALESCE
- INNER JOIN
- LEFT JOIN
- Subquery
- Aggregate functions
- LIMIT and OFFSET
